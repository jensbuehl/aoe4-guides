## T10 audit: phone-reachable tooltips and hover reveals

Class a = information needed to act (must be visible on touch) · b = redundant with a visible label/icon · c = decorative.

| Item | Class | Decision |
|---|---|---|
| Insert menu: reason a disabled option (Alternatives / Advance) is refused | a | Shown inline under the option on no-hover devices |
| Insert menu: "Alt ↵" / "Alt N" shortcut hints | — | Hidden where no fine pointer exists (`any-pointer: fine`; iPad + trackpad keeps them) |
| Phone insert divider lit by sticky `:hover` | — | Open state from the activator's `isOpen`; hover only under `(hover: hover)` |
| Play chooser descriptions (touch PCs, which keep the chooser) | a | Shown inline when there is no hover |
| Touch table editor (landscape phone / tablet): insert line, row ✕, row grip at opacity 0 until hover | a | Fix round 1: shown at rest under `(hover: none)` |
| All `v-tooltip`s on browsers without `sourceCapabilities` (Safari, Firefox) open on tap and stick | — | Fix round 1: global default `openOnHover` = `(hover: hover)` |
| Alternatives tab condition (editor, not stacked) | b | Left — it is also the path's first note card |
| Focus mode prev/next/voice/autoplay/close | b | Left — standard icons with aria-labels |
| Focus mode villager-announcement toggle | b | Left — tapping re-announces the step |
| Focus mode path switch / pick options | b | Left — label visible, conditions inline |
| Picker sheet tab tooltips | b | Left — tab labels and tile names visible |
| Editor icon button ("Add an icon, or type :: …") | b | Left — the button acts on its own; `::` hint out of scope |
| Editor and build ⋮ menus | b | Left — labelled rows, aria-labels, Delete confirms |
| Vote / Favorite / comment | b | Left — universal icons |
| Theme toggle (System/Light/Dark) | b/c | Left |
| Bottom nav, header desktop buttons | b | Left — labelled / desktop-only |
| BuildListCard full-title tooltip | b | Left — full title one tap away |
| AgeTimeline crest (click-up times) | informational | Left — follow-up candidate |
| Season tooltip (dates/expansion) | informational | Left — follow-up candidate (date range as subtitle on touch) |
| Icon tooltip inside step text | — | Reachable (mouseover fires on tap); icon-tap behaviour out of scope |
